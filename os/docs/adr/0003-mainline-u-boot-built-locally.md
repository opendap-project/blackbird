# ADR 0003: Mainline U-Boot, built locally

- **Status:** Accepted
- **Date:** 2026-10-21

## Context

No prebuilt U-Boot works on a custom RK3566 board: DDR init is a Rockchip blob, and vendor binaries embed their own board.

## Decision

- Build **mainline U-Boot** from the generic RK3566/RK3568 configuration, with the rkbin DDR init blob and Debian's prebuilt TF-A BL31, using Debian's prebuilt cross compiler. It is the only build Blackbird OS makes, and it runs locally.
- Package it as a `.deb` in a non-free component, installed by an explicit script, never flashed on package install.
- Boot through extlinux generated by Debian's `u-boot-menu`, which applies device tree overlays. A/B selection uses U-Boot's boot counter and the watchdog.
- Secure boot (OTP keys) is deferred.
